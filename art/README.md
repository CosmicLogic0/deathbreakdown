# Death Breakdown art
Theme (death/combat): dark red + black, bold pixel font (Press Start 2P), a faint "damage log" of hit bars.
- `icon.png`: the icon in use, **option 4 (magnifier over skull), Dylan's pick** (400x400)
- `icon-options/`: option-1 … option-4 (400x400) + `death-breakdown-icon-options.png` (all four side by side)
- `header.png`, `header-plugin.png`: page headers (mod / plugin), 1200x400
- `donate.png`: "Help keep this mod alive" banner, 1200x340
- `source/make_icons.py`: draws the 4 icons · `source/banners.py`: draws the headers + donation banner (run from art/)
Page copies live in each repo's `docs/images/`.
